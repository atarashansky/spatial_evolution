# Round 8 — topology control: hexagonal and random-coordination stencils

**Verdict: FOR.** The order-unity U_d/s_d freeze bar is not an artefact of the square lattice. With the production Moran dynamics unchanged and only the neighbour graph swapped, a fresh 600-run neutral anchor per stencil, and a 9-rung θ ladder (0.05–1.2, 96 runs/rung, s_d = 0.01), the T_fix-crossing ridge is **θ\* = 0.329 [0.241, 0.380] on the hexagonal 6-neighbour lattice** (n = 1,464) and **θ\* = 0.344 [0.286, 0.439] on the random-coordination lattice** (per-site degree ~U{5,6,7}, fixed per run; n = 1,464), versus the square-lattice references Moore 8-nbr θ\* = 0.37 [0.32, 0.43] and von Neumann 4-nbr θ\* = 0.30–0.32. Both new ridges sit inside the Moore/vN envelope, and the ridge/Moore ratios are 0.88 [0.64, 1.07] (hex) and 0.94 [0.74, 1.22] (rand): the bootstrap probability of a ≥2× shift in either direction is zero. The prediction's specific ordering claim also holds: the measured interface coordination is N_eff = 2.30 (hex) and 2.34 (rand), between vN (1.63) and Moore (2.90), and the four ridges order as N_eff orders (0.31 < 0.33 < 0.34 < 0.37) — though the hex–rand step (Δθ\* ≈ 0.014) is not statistically resolved on its own.

## What was run

- **Kernels.** `evolution_strip._run_strip` (T_fix) and `census2._run_census2` (contact census) were used **unmodified**; both are generic in the neighbour index table. New stencils live in `kernels/topo_strip.py` as `_build_nbr` variants only. Acceptance test: with the reconstituted `evolution_fast4` helpers (inlined verbatim in the DFE kernel), the deposited neutral runs at seeds 12,900,000–12,900,002 reproduce **bit-for-bit** (T_fix 1,129,978 / 1,325,918 / 845,779) through both `evolve_strip` and the topology wrapper `evolve_topo(stencil='moore')`.
- **Stencils** on the standard 194×32 grid (192×32 = 6,144 interior sites, x-walls, y-periodic; clone A = columns 1–96): hexagonal = triangular lattice by row offsetting (6 neighbours; boundary columns lose 1–3 to the wall, mean interior degree 5.98); random-coordination = per-site subset of the wall-clipped Moore neighbourhood of size ~U{5,6,7}, drawn from a topology RNG (`seed + 1,000,000,007`) once and frozen for the run (mean degree 5.99; graph is directed — see caveat 3).
- **Protocol.** T_fix arm: numgen cap 20 M frames, dt = 2400, avg = 1.16×10⁻⁵, s_b = 0.1, μ_b = 0, s_d = 0.01, θ = μ_d/s_d ∈ {0.05, 0.0744, 0.1107, 0.1646, 0.2449, 0.3644, 0.5422, 0.8066, 1.2} (geometric), 96 runs/rung, plus 600 neutral (μ_d = 0) anchor runs per stencil. Census arm: `census2` protocol (numgen 1.2 M, sampling 2000, iface_w 3, window 0.10 < t/T_fix < 0.60), θ ∈ {0.05, 0.2, 0.5, 1.0} × 16 runs per stencil, plus a 16-run matched-protocol Moore control.
- **Runs.** 2,928 T_fix runs + 144 census runs = **3,072 runs, 0 errors, 0 T_fix runs censored** at the 20 M cap (max T_fix 5.06 M frames); 6 census runs reached the 1.2 M census cap (their pre-cap window still yields the contact tally). ~21 core-hours.
- **Seeds.** Block 13,500,000–13,519,999 (round-8 topology track), disjoint per (stencil, arm): hex anchor 13,500,000+600, hex rungs 13,501,000… (100-blocks), hex census 13,501,900+64, rand anchor 13,502,000+600, rand rungs 13,503,000…, rand census 13,503,900+64, Moore census control 13,504,000+16. All 3,072 seeds are unique, span 13,500,000–13,504,015, and are disjoint from every seed range in SEEDS.md (all prior campaign bases ≤ 12,900,000 plus legacy tables < 13.5 M). Smoke/timing probes at 13,519,000–13,519,299 are not deposited.
- **Estimator.** Deposited convention verbatim: per-rung median T_fix / own neutral median; first crossing of 1/2 by log-θ-linear interpolation; run-level bootstrap (4,000 replicates) resampling runs within every rung *and* within the neutral anchor. Replicating the deposited square-Moore ladder from `ridge_profile_analysis_pool.parquet` with this code returns θ\* = 0.3725 [0.324, 0.430] (deposited: 0.373 [0.320, 0.431]).

- **Envelope.** Both new point estimates lie inside the Moore/vN corridor [0.302, 0.43]; both CIs overlap the Moore CI; neither is displaced by anything approaching the factor-2 falsification threshold (P_boot(ratio > 2) = 0, P_boot(ratio < 1/2) = 0 for both).
- **Ordering vs N_eff.** vN < hex < rand < Moore in both N_eff and θ\* (Spearman ρ = 1 on 4 stencils). The claim that carries statistical weight is the three-tier separation (vN 1.6 / hex-rand 2.3 / Moore 2.9); the hex-vs-rand step is within noise (bootstrap θ\*_rand/θ\*_hex = 1.07 [0.85, 1.53]).
- **Sensitivity.** Crossing scheme spread ≤ 0.005 (loglin/isotonic/loglog); leave-one-rung-out ranges [0.320, 0.349] (hex) and [0.344, 0.380] (rand); crossing-level dependence θ\*(0.4)/θ\*(0.5)/θ\*(0.6) = 0.45/0.33/0.26 (hex), 0.49/0.34/0.28 (rand) — the same level-sensitivity the deposited Moore profile has, so the comparison is like-for-like at level 1/2.
- **Anchor discipline mattered.** Neutral fixation is 28% slower on the hexagonal lattice and 9% faster on the random one than on the square strip (median 733,866 vs 522,634 vs 572,584 frames). Normalising the hex ladder by the square anchor would have manufactured θ\* = 0.46; the own-anchor rule removes this. This is a pure normalisation effect, not a shift of the freeze/flow physics.

## Adversarial notes and caveats

1. **What would have counted as AGAINST, and why it did not happen.** A missing crossing (ratio never below 1/2 across the ladder), or a crossing outside [0.16, 0.74] (2× of the Moore/vN corridor). The ladders cross cleanly (hex 0 monotonicity violations, rand 2 minor ones smoothed identically by all schemes), and the largest observed departure from Moore is 12% (hex).
2. **The hex CI is asymmetric-wide on the low side ([0.24, 0.38])** because the hex freeze curve descends earlier than Moore at low θ (ratio already 0.72 at θ = 0.16). The point estimate is stable (bootstrap median 0.330, LOO ≥ 0.320), but a reader should quote the CI: the honest statement is "hex ridge between 0.24 and 0.38", overlapping both vN and Moore.
3. **Random-coordination graph is directed.** Site i's neighbour list is drawn independently of j's; the Moran refill uses out-neighbours, so the dynamics is well defined but a birth i→j does not imply j→i is possible. N_eff for this stencil is the out-degree opposite-clone contact count (the quantity the birth rule competes over). A symmetrised variant was not run; if the paper's random-lattice claim intends an undirected graph this is an untested distinction (expected small — mean in-degree = mean out-degree = 6.0, coordination variance is the tested feature).
4. **`wall_pc` for the random stencil (0.96) is a bookkeeping artefact**, not physics: unused padding slots (a k = 5 site has 2 empty slots of 7) point at the dummy wall site and census2 tallies them as "wall" neighbours. The opposite/same tallies used for N_eff are unaffected; the dynamics never selects the zero-fitness dummy. Deposited Moore/vN tables report wall_pc ≈ 0 by construction.
5. **Site count vs geometry.** All stencils use the same 6,144-site grid; the hexagonal metric density (√3/2 row height) is not modelled — coordination graph only, as briefed. A metric hex lattice with 192×32 physical extent would have ~7,094 sites; not tested.
6. **Single s_d.** The topology test is at s_d = 0.01 only, matching the brief and the deposited envelope; portability of θ\* across s_d is a separate (and previously failed) claim, untouched here.
7. **Census N_eff CIs are tight ([2.296, 2.299] etc.) because per-run contact means average over ~10⁵ boundary-cell observations**; run-to-run and θ-to-θ variation is ~0.5%, consistent with the deposited Moore census (2.881–2.912 across θ).
