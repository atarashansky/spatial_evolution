**Fig. S16** — Frequency-dependent selection pins only load-free boundaries (formerly a main-text figure; the clone-fraction coupling variable is Supplementary Fig. S7). Frequency-dependent selection pins neutral boundaries but only slows loaded ones: the model's only pinned phase requires the absence of load.

**Frequency-dependent boundary selection creates the model's only pinned phase — but the pin holds only where mutational load is absent.** Two-clone
strip simulations with a neighbor-dependent decaying clonal advantage of the
kind reported in normal esophageal epithelium (Colom et al., *Nat Genet* 2020,
doi:10.1038/s41588-020-0624-3 — mutant progenitors show a fate bias toward
proliferation when surrounded by wild-type cells that reverts toward
homeostasis as fitter neighbors take over): each lineage's
competition weight is w = 1 + b₀(1 − f), with f its live-cell fraction, so the
minority lineage is favored by a restoring force 2·b₀·(f_maj − 1/2) toward
f = 1/2. The bonus acts only at competition (the fitness-proportional source
draw); stored load fitness is untouched.

**(a)Any bonus pins neutral boundaries; loaded boundaries always escape.**
Median fixation time vs b₀ at 192×32 (Moore, periodic y, symmetric split).
Neutral arms (blue): b₀ = 0 fixes at 513k frames [462k, 576k] (n = 300); every
probed b₀ > 0 abolishes fixation — 0 of 1,200 runs fixed at the 12M-frame cap
(open markers with arrows: censored lower bounds, ≥23× the b₀ = 0 median).
Loaded arms (orange, Λ = μ_d·s_d = 10⁻³, s_d = 0.01): fixation never fails —
zero censoring in all 2,900 loaded b₀ > 0 runs shown (900 pilot runs at a 12M
cap for b₀ ≤ 0.05; 2,000 production runs at a 30M cap for b₀ ≥ 0.1) — but
slows monotonically, 79.6k → 442.5k frames (up to 5.3× the loaded b₀ = 0
baseline of 83k frames from the load-only ensemble of Fig. 2c, dashed; the low end is a ~1× shift). There is no loaded transition point b₀* ≤ 0.5: drift always beats the
restoring force. The cost is paid in fitness: median winner end-fitness falls
0.38 (b₀ = 0) → 0.008 (b₀ = 0.5) — pinning holds the interface while the
ratchet digs deeper. Bootstrap 95% CIs on medians (error bars, mostly smaller
than markers); n = 300–400/point.

**(b) Neutral escape is exponential in b₀ — Ornstein–Uhlenbeck escape, not a
power law.** Median neutral fixation time at reduced geometry 128×24
(M = 3,072 sites, cap 60M, n = 300/point): 239k (b₀ = 0, grey anchor) → 394k →
1.11M → 17.0M frames at b₀ = 0.002/0.005/0.01. The exponential form
ln T = ln T0 + c·b₀·M with c·M = 478 [444, 499] (c = 0.156 per unit b₀·M,
R² = 0.99) beats the best power law (R² = 0.89) in 100% of 2,000 bootstrap
resamples (SSE ratio 8.9). At b₀ = 0.01, 20/300 runs censored at 60M; the
median is identified (7% < 50%) and censored values were treated as +∞ in the
bootstrap. Extrapolating the law to panel (a)'s geometry (M = 6,144) predicts
T ≈ 7×10⁹ frames at b₀ = 0.01 — consistent with the 300/300 censoring observed
there. The clone-fraction zero mode is an OU process: escape time exponential
in barrier b₀·M — the pinned phase is a genuine activated regime, not a slow
crossover.

**(c) The loaded plane has no phase boundary — slowdown collapses on
b₀/√Λ.** Λ × b₀ grid (192×32, n = 200/cell, cap 30M, zero censoring in all
2,400 runs). Orange values: median T_fix ratio to the b₀ = 0 baseline at the
same Λ (baselines 124k/83k/66k at Λ = 2.5×10⁻⁴/10⁻³/4×10⁻³, from the load-only ensembles of Fig. 2c). Grey contours: the fitted collapse ln(T/T0) = 0.150·b₀/√Λ (R² = 0.96;
best-fit exponent for Λ is 0.55 ≈ 1/2). The √Λ scaling identifies the
competition: the OU restoring force (∝ b₀) versus the ratchet's gap drift
(∝ √Λ per unit time). Pinning therefore appears only as an essential
singularity at Λ → 0 (the neutral axis, panel a) — at any Λ > 0 the mosaic is
fluid, merely slowed. The collapse is validated to b₀ = 0.3; at b₀ = 0.5,
Λ = 10⁻³ the measured 5.3× falls below the predicted 10.7× as loaded T_fix
approaches the neutral fixation scale (saturation). Blue band: the b₀ = 1–5% range adopted here to represent a
Colom-type neighbor-dependent advantage — a few-percent early clonal fate
bias that decays as the clone grows (mechanism per Colom et al. 2020; the specific 1–5% bracket is a simulation choice, not a measured value from that study).
Green/purple ranges: per-division load rates Λ for normal human tissues
(colonic crypt to sun-exposed epidermis/HSC, 8×10⁻⁶–8×10⁻³) and hypermutator
tumors (4×10⁻⁴–2.4×10⁻²). Real tissues sit where frequency coupling of the
Colom magnitude slows clonal replacement by only ~1.1–2× — unless load is
effectively absent, in which case the same coupling freezes the mosaic
entirely.

### Supplementary Note S2 | Correction record: the withdrawn kernel-versus-kernel "load signal"

An earlier version of this work reported that mean-rescaled clone-size histograms separated the loaded kernel from the neutral kernel (a "load signal"), and derived a sample-size prescription for detecting it in tissue data. Both are withdrawn. The rescaling step — dividing each clone size by the ensemble mean before histogramming — generates the apparent separation on its own: applied to two disjoint halves of a single *neutral* ensemble, the rescaled KS statistic is 0.0915 at 1 month, indistinguishable from the loaded-versus-neutral value of 0.0918 that had been read as signal. The kernel-versus-kernel comparison therefore carries no information about load, and neither does any sample-size figure derived from it. What survives is stated in the main text and Fig. 7: on the correct, unrescaled statistic with the fitted measurement layer, published clone-size distributions reject the model in every arm and cannot separate loaded from neutral dynamics, so clone size is not the discriminating observable; boundary kinematics is (Fig. 7d and the power specification in Methods). We retain this note so that the correction is auditable rather than silent.
