# clonal_mosaic_release

Simulation kernels, ensemble drivers, and the analysed data behind the manuscript *Deleterious load fluidizes somatic mosaics* (Tarashansky, 2026). Everything here regenerates the paper's figures.

## Layout
- `kernels/` — the seven simulation kernels (`evolution_*.py`); each exposes an `evolve_*` function whose arguments are the model parameters and an integer RNG seed.
- `drivers/` — ensemble drivers (`ensemble_driver.py`, per-track drivers such as `run_fd_production.py`, `rough_driver.py`, `strip_census.py`, `sdr_kernel.py`).
- `data/` — every data file cited in the figure captions and Supplementary Table 1 (`SCHEMAS.json` lists per-file column schemas). The pusher-switch (E6) ensemble lives in `data/pusher_switch/` under its native filenames: `calibration_runs.parquet` (b* transition grid, panel S20a), `ensemble_main.parquet` (plateau/clock/incidence grid, S20b–c), `validation_runs.parquet` + `validation_stats.json` (kernel validation), `refine*_` (transition refinements), with the exact drivers used (`run_ensemble.py`, `run_val_calib.py`, `run_refine2.py`).
- `figures/` — rendered Supplementary Fig. S20 composite and the E6 panel figure.
- `manuscript/` — the manuscript, main and supplementary captions, and supplementary tables as analysed.
- `SEEDS.md` — the RNG seed ranges actually present in every per-run data file.
- `environment.lock` — the Python package versions used.

## Reproduce a run
```python
import sys; sys.path += ['kernels']
import evolution_strip as es
r = es.evolve_strip(L_long=192, L_short=32, sd=0.01, mud=0.004, seed=946000)  # any (kernel, seed) from SEEDS.md
print(r['t_fix'])
```
The neutral control (Supplementary Fig. S1) and one loaded-versus-neutral fixation point are regenerated by `drivers/ensemble_driver.py` with the parameters in Supplementary Table 1.
